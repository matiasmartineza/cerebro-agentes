# Herramientas de Codex

- **Windows y desarrollo.** Puedo usar PowerShell, Git, Python, Node.js, npm y .NET para trabajar con archivos, ejecutar scripts y verificar cambios.
- **Aplicaciones de escritorio.** Tengo conectores MCP para Word, Excel, Anki, Blender, EPANET, Autodesk Inventor, Navisworks y AutoCAD Plant 3D. Puedo automatizar el navegador con Playwright y operar aplicaciones Windows cuando la sesión lo permite.
- **Servicios conectados.** Tengo herramientas para GitHub, Google Drive (Docs, Sheets y Slides), Gmail, Google Calendar, WhatsApp Business, Spotify y Sites. El acceso a contenido y las operaciones disponibles dependen de la cuenta, los permisos y la sesión.
- **Acceso local.** Puedo leer y editar archivos de trabajo del clon, sujeto a las restricciones del entorno. En esta sesión `.git` es de solo lectura y la red de terminal está restringida. Puedo consultar la rama remota con el conector de GitHub.
